## Overview

### Description

Eatsy is a simple and fast app that allows users to search for recipes, view full recipe details, and save their favorite recipes for easy access later.

### App Evaluation

[Evaluation of your app across the following attributes]
- **Category:** Food & Drink
- **Mobile:** Mobile-first experience for quick search and browsing of recipes with minimal friction
- **Story:** Users can easily find new recipes to cook based on what they’re craving and save favorites to revisit later
- **Market:** Home cooks, students, busy professionals — anyone who needs quick inspiration for meals.
- **Habit:** Users open the app to search recipes on demand, maybe a few times a week — especially before cooking or grocery shopping
- **Scope:** Search, View, Save. Future versions could add meal plans, sharing, or grocery integrations

## Product Spec

### 1. User Stories (Required and Optional)

**Required Must-have Stories**

* User can search for recipes by keyword.

* User can view a list of search results

* User can tap a recipe to view full recipe details (ingredients + steps).

* User can favorite a recipe.

* User can view a list of saved favorite recipes.

**Optional Nice-to-have Stories**

* User can filter search results by diet type (e.g., vegetarian, gluten-free).
* User can search by ingredient (e.g., "chicken" returns recipes using chicken).

User can pull-to-refresh search results
